# Demonstration evidence

This directory contains committed, sanitized evidence generated by the README demo path.

The retained evidence set includes:

- `prepare-internal-transfer.v1.json`: the typed, versioned draft capability produced by genuine LLM discovery;
- `discovery-a26d5116-1e4e-48de-9430-11f6428c60ac`: genuine goal-only LLM discovery and final review screenshot;
- `replay-3d214bf8-9e7b-40cc-84c4-a7814476bd3a`: deterministic successful replay with different inputs;
- `replay-0719702f-aa53-451a-bb45-4284e3f27c9d`: declared `MEMBER_NOT_FOUND` business outcome;
- `replay-9cf5b705-06ce-4529-a86b-2e0834c37b5e`: bounded transient recovery and verified completion;
- `replay-handoff-demo-dd2973e5-3702-4193-9a5f-57fa6686b9b4`: scripted operator simulation proving same-session control transfer, manual-event capture, checkpoint verification, and resume;
- `api-replay-97fb2574-2fe6-4935-956d-78642939f863`: the saved capability invoked through the agent-facing HTTP API with no model in the loop.

The interactive human-operated version uses `npm run replay -- --handoff` as documented in the root README. The scripted operator run exists only to make this evidence reproducible in CI.

No API keys, cookies, credentials, raw PII, or model chain-of-thought belong here.
