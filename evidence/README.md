# Demonstration evidence

This directory is reserved for committed, sanitized evidence generated by the exact README demo path.

The final evidence set will include:

- a typed saved capability artifact;
- a genuine LLM discovery JSONL log;
- a deterministic successful replay log using different inputs;
- a known-business-outcome replay;
- a recoverable transient-condition replay;
- an intervention and same-session resume replay;
- redacted screenshots and Playwright traces where useful.

No API keys, cookies, credentials, raw PII, or model chain-of-thought belong here.
